# 工厂管理系统 · 排产甘特图与业务操作

本仓库是工厂管理系统的前端工作台，包含 11 个部门宫格导航、员工和岗位权限、成员私聊界面、办公位置以及业务单据操作。

## 排产甘特图

生产计划与物料控制部（PMC）的排产甘特图以时间为横轴、产线与检验工位为纵轴。生产任务包括配制、包装；**非生产任务包括清洗、调机调线**，两者都独立建单并记录开工、完工和复核；QC 检验、QA 放行也列在时间轴上。

## 新增制造运营功能

- 工厂运行总览、电子操作标准卡及受控版本执行记录。
- QA/QC 报检判定、抽检、清洗报检、不合格品处置与质量库存。
- 车间领料申请、仓库 FIFO 备料、双签接收、结余退库、工时申诉审批和返洗返工。
- 仓库来料比对 → QC 判定 → 入库确认，以及效期批次、冻结、月末收发存。
- 产线 × 岗位排班、技能及请假校验、开工前 Gate、员工班次工时确认、订单日报表。
- 信息化部统一维护权限组织、流程规则、操作标准卡、工艺模板、BOM、产品物料和基础字典。

用户提供的五类库存历史汇总只展示快照，不作为可发库存。上述功能的数据均保存在浏览器，不构成正式服务端审批或签名。

## 主要交互

- 销售订单：新建、修改、提交评审、评审通过或退回。
- 生产计划与物料控制部（PMC）：排程试算、正式排程发布、根据 BOM 和库存检查齐套并锁库。
- 采购与仓库：采购单创建、审批、到货入库、发料、库存调整与成品入库。
- 生产与质量：清洗及调机调线独立任务（开始、提交复核、确认复核）；配制开工/报检、半成品检验、包装开工/报检、成品检验、QA 放行。
- 主数据：产品与物料、BOM 单位用量、受控工艺模板版本、技能矩阵、人员档案和岗位排班。
- 其他：重大事项审批、财务单据、加班和生产激励审批。EHS 安全检查已移除，工艺技术业务已并入信息化部。

订单主流程在不同部门页面使用同一批数据。库存不够时不能锁库；清洗未复核不能配制；调机调线未复核不能包装；QA 未放行不能入库。每次状态变化保留操作记录。

## 运行方式

仓库通过 `.github/workflows/pages.yml` 自动发布到 [在线工作台](https://lee7017.github.io/factory/)。本地可运行：

```bash
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080`。

## 数据边界

GitHub Pages 不运行 Node.js 和 SQLite。此版本的记录仅保存在当前浏览器 `localStorage`，**不是真实员工间共享的数据，不提供真实服务端权限保护，也不会向其他员工发送消息**。岗位与个人权限在前端用于检查页面交互与流转设计；正式生产环境仍需在 Node.js 后端复用并验证这些操作规则。

## 主要文件

- `index.html`：页面骨架。
- `styles.css`、`layout.css`、`ui-theme.css`、`operations.css`：布局、黑白玻璃主题和业务操作组件样式。
- `access.js`：多岗位、个人权限并集。
- `app.js`：部门导航、部门成员、聊天和公共交互。
- `operations.js`：业务记录、操作表单、状态校验、跨部门流程和操作记录。

回归测试可参考 `tests/test_workflow.py`，包含采购缺料、清洗和调线前置校验，以及订单到成品入库的跨部门流程。


## 部门首页与流转反馈（V19）

- 部门总览拆分为「业务功能」「部门成员」「待办」三个 Tab，仅展示实际业务功能，成员可按姓名/工号/岗位搜索，待办按待处理/进行中/待审核复核三列呈现。
- 订单操作成功后，页面中央展示操作部门 → 下一处理部门、动作、单据状态、下一步及本单近期历史，并自动淡出。清洗、领退料、质检等模块的保存操作也会显示流转反馈。
- 全厂最近操作记录集中到「工厂运行总览」，业务页不再重复放全局日志；单据详情保留本单历史。
- 点击锁定功能仍仅原地泛红，不出现流转动画；以上数据仍保存在当前浏览器，跨员工设备消息需要后端。

## 视觉规范（V23）

`ui-theme.css` 是主题文件：主色调保留黑白灰，绿色只作为玻璃下方的背景层，通过半透明背景、背景模糊和边缘高光展示毛玻璃的透感。左侧 11 个部门采用两列方形宫格（大图标在上、名称在下），中间真实业务功能采用独立 SVG 和半透明卡片，不再填充空白占位格。移动端保留抽屉式部门导航与响应式功能宫格。已保存的旧工艺权限会在浏览器内迁移到信息化部；历史安全检查记录保留在本地数据，但不再提供 EHS 功能入口。旧版 `theme-v15.css` 不再由页面引用。
